# NeonIDe — Nokia HTML Edition

**Lightweight HTML IDE for Nokia E6.**

NeonIDe is a native HTML code editor developed in C++ and Qt 4.7 for Symbian devices.

## Features

- HTML tag autocomplete
- Automatic closing tags
- HTML document template generation
- Syntax highlighting
- Code editing
- HTML preview in the device browser
- File opening and saving

## Technology

- C++
- Qt 4.7
- Symbian OS
- Nokia E6

## Building

1. Install Nokia Qt SDK 1.2.1.
2. Open `NeonIDe.pro` in Qt Creator.
3. Select `Symbian Device`.
4. Choose Release configuration.
5. Build the project.
6. Install the generated SIS package on your Nokia E6.
